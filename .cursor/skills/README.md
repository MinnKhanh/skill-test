# Local Skills For This Repo

## Mục đích
Bộ skill nội bộ để chuẩn hóa cách triển khai API trong repo này.

## Danh sách
- `api-task-execution`: Luồng triển khai endpoint theo chuẩn Service + FormRequest + Resource.
- `api-error-logging`: Chuẩn lỗi, mã lỗi, logging có ngữ cảnh.
- `api-test-verify-gate`: Cổng test/verify trước khi chốt task.

## Cách dùng gợi ý
1. Dùng `api-task-execution` khi bắt đầu API task.
2. Dùng `api-error-logging` khi xử lý lỗi/ngoại lệ hoặc chuẩn hóa response lỗi.
3. Dùng `api-test-verify-gate` trước khi kết luận hoàn tất.
